Artifact Enhancements

Enhancement One: Software Design and Engineering

For this enhancement, I revisited my CS 330 computational graphics project created with C++ and OpenGL. The project demonstrates the construction of a three-dimensional scene using meshes, transformations, textures, materials, and lighting.

I selected this artifact because it provided an opportunity to improve an existing application rather than simply create another program from the beginning. I focused on improving the structure, organization, modularity, and maintainability of the code while preserving the visual behavior of the original scene.

The enhancement demonstrates skills in object-oriented programming, modular design, code organization, debugging, documentation, reusable software components, and maintainable software development. Revisiting the project also reinforced the importance of evaluating existing code and improving its internal design even when the original implementation already produces the expected result.

Enhancement Two: Algorithms and Data Structures

For the algorithms and data structures enhancement, I used my CS 330 3D Desk Lamp project. The project was originally developed using C++ and OpenGL and renders a three-dimensional desk lamp using multiple meshes, transformations, textures, materials, and lighting.

I enhanced the project by creating a SCENE_OBJECT structure and organizing the scene objects inside a vector. The BuildSceneObjects() function creates the objects and stores them in the collection, while RenderScene() iterates through the collection and sends each object through a reusable rendering method.

This approach removed repeated rendering logic and made the scene easier to maintain and expand. Instead of creating separate rendering logic for every new object, additional objects can be stored in the collection and processed using the same algorithm.

Building and rendering the object collection both operate in O(n) linear time, where n represents the number of scene objects. Evaluating the complexity of these operations helped me consider not only whether the program worked correctly, but also how the organization of the data and the rendering algorithm affect the scalability and maintainability of the application.

Enhancement Three: Databases

The database artifact is the Travlr Getaways application that I originally developed in CS 465 Full Stack Development I. Travlr is a MEAN-stack web application that uses MongoDB, Express.js, Angular, and Node.js to manage travel information.

I strengthened the database implementation by improving Mongoose schema validation and API error handling. Validation is applied during both create and update operations. The price field was changed to a numeric value with a nonnegative validation rule, and the start date uses the Date data type.

I also added API validation tests using Jest and Supertest. The tests verify that invalid POST and PUT requests return appropriate 400-level responses instead of allowing invalid information to enter the application.

These changes improve data integrity, reliability, maintainability, and the overall quality of the application. This enhancement also reinforced the connection between database design and application security because validation helps protect the system from malformed or inappropriate data before it is stored.
